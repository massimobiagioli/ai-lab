# Manual BDD scenarios

A scenario that cannot be automated is tagged `@manual` in the generated feature and listed here with an owner, a reason, the required human evidence and a review date. An empty table means every current scenario has an automated step definition or is still listed by the coverage report as pending automation.

Pending automation is tracked in `reports/coverage.json`; it is not a manual scenario and is never reported as passed.
