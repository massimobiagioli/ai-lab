## context

The 2026-11-09 mega-review found no documentation manifest, no acceptance report and no handover, and the release/SBOM/signing evidence was deferred to a follow-up that never ran. P15 delivers the SBOM, signing, release 1.0 and the QA verdict. WP-22 closes only when QA is `APPROVED` and every AC-001..015 has linked evidence.
