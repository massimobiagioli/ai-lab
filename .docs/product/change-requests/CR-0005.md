# CR-0005 — Align the technical specification TypeScript pin with ADR-0024

## context

The technical specification §5.1 pins TypeScript **7.0.x**. Angular 22.2 declares a peer range of `>=6.0 <6.1`, so TypeScript 7.0.x is not installable without overriding the peer dependency. ADR-0024 records the decision to use 6.0.x and `.docs/STACK.md`, `web/package.json` and WP-02 §3.4 already implement it. The normative specification was never amended, so the highest source of truth contradicts the delivered stack (Constitution source-of-truth order and non-negotiable #5).

## proposed_change

Change the specification §5.1 row `Language | TypeScript | **7.0.x**` to `6.0.x (ADR-0024; Angular 22.2 peer range >=6.0 <6.1)`. No code change; the implementation already matches.

## impact_scope

- `.docs/technical-specification/AI-LAB-TECHNICAL-SPECIFICATION.md` §5.1
- `.docs/product/change-requests/README.md`
- No WP, card or contract change; ADR-0024 remains the decision record.

## impact_schedule

None.

## impact_cost

None.

## impact_risk

Pinning an older major delays TypeScript 7 features until Angular widens its peer range. Revisit when Angular supports TypeScript 7 (tracked by Renovate and ADR-0024).

## alternatives

1. Keep the spec at 7.0.x and override the Angular peer dependency. Rejected: unsupported combination, breaks `ng build`/`ng test`.
2. Upgrade Angular early. Rejected: out of the approved stack and not required by any WP.

## decision

`approved`. Amend §5.1 to 6.0.x and link ADR-0024.
