# Budget exhausted

- **Detect:** `AilabBudgetExhausted`, `BUDGET_EXCEEDED` run outcome, lab paused.
- **Check:** the lab/card budget and spend, the cost ledger, the current autonomy.
- **Mitigate:** keep the lab paused, raise the budget with the owner's approval, requeue after the budget is increased.
- **Escalate:** Tech Lead + budget owner.
