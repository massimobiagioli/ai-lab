## Story

As the Tech Lead,
I want the 16 required CI contexts enforced on the default branch,
so that no change can merge without the AI-Lab quality gates.

### Context

WP-00 delivered `.github/required-checks.txt`, `.github/branch-protection.json` and the documentation in `.docs/product/quality-gates.md` §7. This environment has no Git repository or GitHub remote, so the operator action could not be executed. This card tracks the action to completion and its evidence.

## Acceptance criteria

Given a GitHub remote and the `main` default branch
When the operator applies `.github/branch-protection.json`
Then the branch requires all 16 contexts listed in `.github/required-checks.txt`
And a new commit dismisses stale approvals
And force pushes and deletions are blocked.
