# ADR-0016 — Three-tier memory with SQL-level scope isolation

## Context

Agents need lab, project and agent knowledge without leaking private notes across scopes.

## Decision

Store memory documents and chunks with an explicit scope and filter by scope in SQL before ranking. Agent A cannot retrieve agent B's scope. Hybrid retrieval combines vectors, full-text and recency.

## Consequences

Useful, cited context with strong isolation. Retrieval quality and storage growth require evaluation and compaction.

## Alternatives considered

A single global memory. Rejected because it leaks private context and dilutes relevance.

Accepted on 2026-11-07 by Tech Lead, QA.
