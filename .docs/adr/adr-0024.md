# ADR-0024 — TypeScript 6.0.x for Angular 22.2 compatibility

## Context

The technical specification and `.docs/STACK.md` pin TypeScript 7.0.x, and the same sources pin Angular 22.2.x. The published Angular 22.2 packages declare a peer dependency of `typescript >=6.0 <6.1`. TypeScript 7.0.2 is published but is outside that range, so a workspace with Angular 22.2 and TypeScript 7.0 cannot install or build without ignoring peer dependencies. The two pins are mutually incompatible.

## Decision

Pin TypeScript to the Angular-supported 6.0.x line (currently `~6.0.2`) for the v1 frontend. Update `.docs/STACK.md` and WP-02 §3.4 to 6.0.x with a reference to this ADR. Renovate must not auto-upgrade TypeScript across the major boundary until Angular declares support for TypeScript 7.

## Consequences

- The Angular workspace builds with supported dependencies and no peer-dependency override.
- The specification's TypeScript 7.0.x line is not met in v1; this is a recorded deviation, not a silent one.
- A future Angular major that supports TypeScript 7 requires a new ADR and a full frontend regression.
- The `strict` and extra type-safety flags remain enabled, so the quality bar is unchanged.

## Alternatives considered

1. Use TypeScript 7.0 and ignore the Angular peer dependency. Rejected: unsupported combination, high risk of compiler and tooling failures.
2. Downgrade Angular below 22.2. Rejected: contradicts the pinned frontend baseline and the design system work.
3. Delay the frontend workspace until Angular supports TypeScript 7. Rejected: blocks WP-02 and the M0 gate for an unquantified period.
4. Use TypeScript 6.0.x and record the deviation. Accepted.

Accepted on 2026-11-07 by Tech Lead and Dev.
