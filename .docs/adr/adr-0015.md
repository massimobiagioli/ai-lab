# ADR-0015 — Structured outputs validated against JSON Schema

| Field | Value |

| Status | accepted |
| Date | 2026-11-07 |
| Deciders | Tech Lead, QA |

## Context

Free-form LLM output cannot be safely persisted, materialized or verified.

## Decision

Require JSON Schema for structured artifacts (SOW, plan, idea cards, reflection, review verdict). Validate on the server, repair once, then fail with a diagnostic.

## Consequences

Reliable artifacts and precise errors. The schema must evolve carefully and prompts are larger.

## Alternatives considered

Parse free-form text with regex or best effort. Rejected because failures would be silent and costly.
