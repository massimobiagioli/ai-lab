# ADR-0010 — Fixed agent roles and a finite character roster

## Context

Agent behavior must be predictable and permissioned, while the office needs distinctive, memorable personas.

## Decision

Use fixed roles (`tech_lead`, `analyst`, `dev`, `qa`) with server-enforced permissions and a finite 10-character roster from Appendix C. Characters affect tone and visuals only, never permissions.

## Consequences

Clear accountability and a consistent office aesthetic. Adding a character requires art, a palette and a spec update; adding a role requires a product decision.

## Alternatives considered

Free-form agent roles and generated avatars. Rejected because permissions and behavior would become unpredictable.

Accepted on 2026-11-07 by Tech Lead, QA.
