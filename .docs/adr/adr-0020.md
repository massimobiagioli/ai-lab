# ADR-0020 — Docker Compose as the supported deployment

| Field | Value |
|---|---|
| Status | accepted |
| Date | 2026-11-07 |
| Deciders | Tech Lead, QA |
| Supersedes | — |

## Context

The product targets a single operator and must be installable in minutes without a cluster.

## Decision

Ship Docker Compose profiles for core, development, observability, TLS and egress. Use named volumes, healthchecks, resource limits and private networks. Kubernetes is out of scope for v1.

## Consequences

Simple installation, reproducible local environments and low operational cost. Scaling is manual and limited to a single host.

## Alternatives considered

Kubernetes or a managed platform. Deferred because it adds operational complexity without a v1 need.
