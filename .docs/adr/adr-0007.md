# ADR-0007 — Canvas 2D pixel office at 384x216 internal resolution

## Context

The virtual office must feel like a 16-bit Amiga-era game, run at 60 FPS and remain deterministic and testable.

## Decision

Render with Canvas 2D at an internal resolution of 384x216, integer-scale with nearest-neighbor, cache static layers and drive animations from backend events. WebGL2 is an optional backend behind a capability flag.

## Consequences

Pixel-perfect visuals, low GPU requirements and deterministic screenshots. Canvas 2D requires careful batching and allocation discipline.

## Alternatives considered

DOM/CSS sprites or a full game engine. Rejected for performance, pixel fidelity and bundle size.
