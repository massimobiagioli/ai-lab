## Context

The office hot loop must not trigger change detection per frame, and the UI needs a modern, strict, testable framework.

## Decision

Use Angular 22 standalone components, signals and `provideZonelessChangeDetection()`. RxJS is used only at boundaries. No NgModules for new code and no zone.js.

## Consequences

Predictable performance, simpler state flow and smaller bundles. The team must avoid zone-based assumptions in third-party code.

## Alternatives considered

Angular with zone.js. Rejected because per-frame change detection conflicts with the office performance budget.
