# ADR-0013 — Login-less local-first with a token for remote exposure

| Field | Value |
|---|---|
| Status | accepted |
| Date | 2026-11-07 |
| Deciders | Tech Lead, QA |
| Supersedes | — |

## Context

The product is designed for a single operator on a local machine. A full identity system would add complexity without a v1 user.

## Decision

Default to loopback with no login. If the bind address is not loopback, require a bearer token of at least 32 bytes and TLS; refuse to start otherwise.

## Consequences

Simple local experience and a safe remote path. There is no per-user attribution or RBAC in v1; the operator is the only human actor.

## Alternatives considered

Full authentication and RBAC in v1. Deferred because it is out of scope and would delay the product.
