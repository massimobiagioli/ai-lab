# ADR-0019 — Conventional Commits with AI-Lab trace trailers

## Context

Agent-authored commits must be traceable to a card, a run and an agent, and history must be readable.

## Decision

Require Conventional Commits and the trailers `AI-Lab-Run`, `AI-Lab-Card`, `AI-Lab-Agent`. Enforce in the commit-msg hook and review.

## Consequences

Readable history, changelog generation and end-to-end traceability. Agents must format messages correctly and CI must reject violations.

## Alternatives considered

Free-form commit messages with external mapping. Rejected because traceability would depend on a separate lookup.

## Status

Accepted on 2026-11-07 by Tech Lead, QA.
