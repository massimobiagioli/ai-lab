## Context

The Kanban board is the source of truth for work. Client-side validation alone would allow invalid states through API calls or retries.

## Decision

Enforce columns, transitions, DoR/DoD, WIP limits and separation of duties in the server transition service. The UI renders violations and never constructs a transition the server would reject.

## Consequences

A reliable, auditable workflow and a single source of truth. The server must return precise, machine-readable violations.

## Alternatives considered

Client-side-only validation. Rejected because it is bypassable and unauditable.

Accepted on 2026-11-07 by Tech Lead, QA.
