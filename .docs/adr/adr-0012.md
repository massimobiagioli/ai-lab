# ADR-0012 — Ephemeral sandboxed runner containers

| Field | Value |
|---|---|
| Status | accepted |
| Date | 2026-11-07 |
| Deciders | Tech Lead, QA |
| Supersedes | — |
| Superseded by | — |

## Context

Agents execute code and shell commands. The host and secrets must be protected.

## Decision

Run every attempt in an ephemeral container: non-root, read-only root filesystem, dropped capabilities, no host mounts, no Docker socket, network disabled by default and allowlisted egress through a proxy. The runner controls Docker through a restricted socket proxy.

## Consequences

Strong isolation and reproducible execution. Sandbox startup adds latency and the runner becomes a critical service.

## Alternatives considered

Execute on the host or in the API process. Rejected due to unacceptable blast radius.

## Status

Accepted on 2026-11-07 by Tech Lead, QA.
