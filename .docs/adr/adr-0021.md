# ADR-0021 — Office engine decoupled from Angular

## Context

The office hot loop must be testable, deterministic and independent of framework change detection.

## Decision

Implement the engine in plain TypeScript under `web/src/lib/office` with no Angular imports. Angular hosts it, feeds a snapshot signal and receives interaction events.

## Consequences

Unit-testable simulation, deterministic visual tests and no per-frame change detection. A bridge layer must be maintained.

## Alternatives considered

Implement the engine inside Angular components. Rejected because framework coupling would hurt performance and testability.

## Status

Accepted on 2026-11-07 by Tech Lead, QA.
