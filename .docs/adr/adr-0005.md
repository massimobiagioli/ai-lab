# ADR-0005 — DeepSeek as the first LLM provider behind a port

| Field | Value |
|---|---|

## Context

The product needs a capable, cost-efficient LLM with tool calling and reasoning. Provider lock-in must be avoided.

## Decision

Define an `LlmProvider` port and implement DeepSeek first: `deepseek-flash` as the default and `deepseek-v4-pro` for justified escalation. Base URL, models, costs and limits are configuration.

## Consequences

Fast delivery with a known provider and a clean path to add others. The product depends on DeepSeek availability and pricing; circuit breaking, queues and budgets mitigate this.

## Alternatives considered

Direct provider-specific calls without a port. Rejected because it would spread vendor details across the codebase.
