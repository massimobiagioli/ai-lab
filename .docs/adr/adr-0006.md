# ADR-0006 — Local embeddings with fastembed

## Context

Memory retrieval needs embeddings without introducing a second external vendor, secret or network dependency.

## Decision

Use `fastembed-rs` with `BAAI/bge-small-en-v1.5` (384 dimensions) and store vectors in pgvector. Embedding model changes require a new table, backfill and swap.

## Consequences

Private, deterministic and cheap embeddings. Quality is lower than large hosted models; the retrieval evaluation and hybrid lexical signal compensate.

## Alternatives considered

Hosted embedding API. Rejected for v1 due to another vendor, cost and data-egress surface.

## Status

Accepted on 2026-11-07 by Tech Lead, QA.
